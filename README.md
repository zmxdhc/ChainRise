# ChainRise

ChainRise orchestrates decentralized, real-time data processing through an asynchronous service engine, facilitating auto-scaling and adaptive performance.

With ChainRise, you get a lightweight tool that stays out of your way.

**What you get**

- ChainRise orchestrates decentralized, real-time data
- processing through an asynchronous service
- engine, facilitating auto-scaling and adaptive

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainRise.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ChainRise is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
